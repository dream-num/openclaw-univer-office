# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting page for this repository:

https://github.com/dream-num/openclaw-univer-office/security/advisories/new

Describe the affected version, impact, and reproduction steps. Remove Workspace credentials,
access tokens, private document content, and private URLs from the report unless they are strictly
required to reproduce the issue.
